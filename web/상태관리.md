✅ Flutter Web 상태 관리 심화 학습 (GetX & Riverpod)

Flutter Web에서 상태 관리를 제대로 활용하면, 대규모 프로젝트에서도 유지보수가 쉬워지고 코드가 더 깔끔해져.
이제 GetX와 Riverpod을 활용한 상태 관리 심화 학습을 진행해볼게! 🚀

📌 1. 상태 관리 개념 정리

Flutter에서 상태 관리란 앱의 데이터(변수) 변화를 감지하고, 이에 따라 UI를 자동으로 업데이트하는 것을 의미해.

🔹 상태 관리가 필요한 이유?
	•	여러 위젯에서 같은 데이터를 공유할 때 (예: 로그인 상태, 테마 변경)
	•	비효율적인 setState() 호출을 줄이고 성능 최적화
	•	전역 상태를 다루면서 구조적인 코드 유지

💡 Flutter Web에서 특히 중요!
→ 브라우저에서 새로고침해도 상태를 유지해야 할 경우, GetX/Riverpod이 유용!

🔥 목표:

```dart

  flutter:
    sdk: flutter
  get: ^4.6.5
```
📌 터미널에서 실행

flutter pub get

📌 Step 2: GetXController를 사용한 상태 관리

🔥 카운터 값을 관리하는 GetX 상태 관리 예제
```dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      title: 'GetX 상태 관리',
      home: CounterPage(),
    );
  }
}

class CounterController extends GetxController {
  var count = 0.obs; // 상태 변수를 .obs로 선언

  void increment() {
    count++;
  }
}

class CounterPage extends StatelessWidget {
  final CounterController controller = Get.put(CounterController());

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('GetX 상태 관리')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Obx(() => Text('Count: ${controller.count}', style: const TextStyle(fontSize: 24))),
            const SizedBox(height: 20),
            ElevatedButton(
              onPressed: controller.increment,
              child: const Text('카운트 증가'),
            ),
          ],
        ),
      ),
    );
  }
}
```
✅ “Obx”를 사용하여 UI를 자동 업데이트
✅ “Get.put()“을 사용하여 상태를 글로벌하게 관리

📌 Step 3: URL 파라미터로 상태 관리하기

Flutter Web에서는 URL이 바뀌면 상태를 유지해야 할 경우가 많아.
📌 GetX의 Get.parameters 활용 예제
```dart
import 'package:flutter/material.dart';
import 'package:get/get.dart';

void main() {
  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp(
      title: 'GetX 상태 관리 - URL 파라미터',
      initialRoute: '/',
      getPages: [
        GetPage(name: '/', page: () => HomePage()),
        GetPage(name: '/details/:id', page: () => DetailsPage()),
      ],
    );
  }
}

class HomePage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('홈 페이지')),
      body: Center(
        child: ElevatedButton(
          onPressed: () => Get.toNamed('/details/123'),
          child: const Text('디테일 페이지로 이동'),
        ),
      ),
    );
  }
}

class DetailsPage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    String id = Get.parameters['id'] ?? '없음'; // URL 파라미터 가져오기
    return Scaffold(
      appBar: AppBar(title: Text('디테일 페이지: $id')),
      body: Center(child: Text('전달된 ID: $id')),
    );
  }
}
```
✅ Get.toNamed('/details/123') → URL에 데이터를 포함시켜서 이동
✅ Get.parameters['id'] → URL에서 파라미터 가져와서 상태 관리

✅ 3. Riverpod 상태 관리 심화 학습

📌 Riverpod 패키지 설치

  flutter:
    sdk: flutter
  flutter_riverpod: ^2.0.0

📌 터미널에서 실행

flutter pub get

📌 Step 1: StateProvider를 이용한 상태 관리

🔥 카운터 앱을 Riverpod으로 변환
```dart
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';

void main() {
  runApp(const ProviderScope(child: MyApp()));
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Riverpod 상태 관리',
      home: CounterPage(),
    );
  }
}

final counterProvider = StateProvider<int>((ref) => 0);

class CounterPage extends ConsumerWidget {
  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final count = ref.watch(counterProvider);
    return Scaffold(
      appBar: AppBar(title: const Text('Riverpod 상태 관리')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text('Count: $count', style: const TextStyle(fontSize: 24)),
            const SizedBox(height: 20),
            ElevatedButton(
              onPressed: () => ref.read(counterProvider.notifier).state++,
              child: const Text('카운트 증가'),
            ),
          ],
        ),
      ),
    );
  }
}
```
✅ StateProvider를 사용하여 상태 관리
✅ “ref.watch(counterProvider)“로 상태를 감지

📌 Step 2: FutureProvider를 활용한 API 연동

📌 HTTP 요청을 처리하는 Riverpod 예제
```dart

import 'package:flutter/material.dart';
import 'package:get/get.dart'; // GetX 패키지 가져오기

// 1️⃣ 카운터 상태를 관리하는 컨트롤러 생성
class CounterController extends GetxController {
  var count = 0.obs; // ✅ obs 사용하여 반응형 변수 생성

  void increment() {
    count++; // ✅ count 값을 증가시키면 UI가 자동으로 업데이트됨
  }
}

void main() {
  runApp(const MyApp()); // 2️⃣ 앱 실행
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return GetMaterialApp( // ✅ GetX를 사용하려면 GetMaterialApp 필요
      title: 'GetX 상태 관리',
      home: CounterPage(), // 3️⃣ 카운터 페이지로 이동
    );
  }
}

// 4️⃣ 카운터 UI 페이지
class CounterPage extends StatelessWidget {
  final CounterController controller = Get.put(CounterController()); // ✅ 컨트롤러를 전역으로 등록

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('GetX 상태 관리')),
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            // 5️⃣ Obx 위젯을 사용하여 count 값이 변경될 때 자동 업데이트
            Obx(() => Text(
              'Count: ${controller.count}', 
              style: const TextStyle(fontSize: 24),
            )),
            const SizedBox(height: 20),
            // 6️⃣ 버튼 클릭 시 count 값 증가
            ElevatedButton(
              onPressed: controller.increment, // ✅ 컨트롤러의 increment() 실행
              child: const Text('카운트 증가'),
            ),
          ],
        ),
      ),
    );
  }
}
```
✅ FutureProvider로 API 연동
✅ users.when()을 사용하여 상태 감지 & UI 변경
